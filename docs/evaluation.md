## 度量定义

Recall@5 = 前 5 个去重藏品中命中的相关藏品数 / 本题全部相关藏品数；MRR = 首个相关藏品排名倒数的平均值。当前每题一个相关藏品，Recall 恰好等同命中率，但实现按一般定义计算。

实际回答需人工分别评：事实正确、逐条引用是否支撑、是否完整回应、是否应该拒答、风格是否合适。核对模型与回答模型同源，可能共享偏差，不能代替人工金标准。
