# 256-token 重排证据：完整 196 项回归

2026-10-07。短证据版（v3）已完成全部 196 条评测记录、3,929 对问题—候选评分。实际为 **114 个不同问题**在两个语料规模上的组合（小库 82、大库 114），不是 196 道互相独立的新题。相对最初的完整 v1 重排结果，小库前五命中不变，大库修复两条退化，没有新增前五失败。**首位仍存在相似作品交换，CPU 耗时仍需控制；网页尚未接入。**

## 本轮改动

沿用[证据补齐版 v2](reranker-context-evaluation.md)的选择顺序和来源约束，只将组装预算从 512 改为 **256 tokens（包含问题、资料及特殊标记）**。模型本身的最大长度仍为 512；这是先挑选可装入预算的完整原文片段，不是让 tokenizer 强行截断文本。

没有修改模型、候选池、问题、正例、来源记录、检索方式或图像算法。固定 BGE-reranker-v2-m3 修订 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`，CPU float32、4 线程、batch size 4，与此前一致。

- 196 条问题、候选身份和候选顺序逐项检查一致。
- 实际输入最长 256 tokens，模型截断数为零。
- 662 对输入因预算省略了部分新增内容；共省略 759 段邻段、294 段摘要开头、302 段摘要续段。该冻结集内没有删掉原先命中的片段、作品属性或简述，不代表未来任意长输入也一定保得住这些内容。
- 全部片段保留来源 ID、选择原因和预算遗漏记录；原馆方资料与旧实验结果未覆盖。

## 耗时与实验顺序

先运行固定 8 道诊断，再运行全部 196 道，最后单进程 AB/BA 复核耗时。8 道诊断的 v3 排名与 v2 完全一致，前五均为 8/8、首位均为 7/8；这一步通过后才启动全量。

| 本轮全量 v3 | 重排 P50 | 重排 P95 | 最长 |
|---|---:|---:|---:|
| 小库题集 | 6.35 秒 | 9.75 秒 | 15.11 秒 |
| 大库题集 | 6.60 秒 | 9.14 秒 | 11.77 秒 |

只计本地问题—证据编码和模型评分，不含召回、生成、HTTP、模型加载；单次顺序运行，不是并发 SLA。8 道诊断的 v3 P50 为 11.35 秒，与全量运行存在负载波动，不能将不同时间的数字当作严格提速对照。

随后在同一进程按 v2→v3、v3→v2 交替计时，每个版本各运行两次：

| 诊断题 | v2 平均 | v3 平均 | 排名与解释 |
|---|---:|---:|---|
| F07 木雕 | 11.81 秒 | 7.03 秒 | 两版均第 1；18 件候选中有 7 件缩短了输入，本例耗时减少约 40.5% |
| G01 花瓶 | 5.30 秒 | 5.28 秒 | 两版均第 2；19 件候选输入完全相同，作为负对照，无可主张的提速 |

这支持“缩短长证据可减少本地计算量”，不能据两道题宣称整体提速 40.5%。也不能直接将前一轮 24 秒与本轮 7 秒相比；电脑负载明显影响了跨轮计时。
