# 文字重排接入、时间预算与回退

2026-10-07。已把[256-token 本地重排](compact-reranker-evaluation.md)接到文字问答入口，公开默认关闭；本地 112 件藏品网页已开启小范围试用。完成 196 项候选对齐、真实本地模型的隔离 HTTP 接入检查与超时恢复验证，以及下述桌面浏览器验收。**未做手机、负载或完整生成问答质量验收。**

## 行为

先取得原有搜索结果作为回退，再由独立的实验检索通道生成候选：administrative 语义输入、每路 Top25、作品级 RRF、256-token 原文组装和固定 BGE 重排。返回前再次检查来源状态和版本。

- 开关关闭：原搜索逻辑不变，不加载重排模型或额外索引。
- 开关开启且本地向量模型可用：为文字问答使用实验通道；默认预算为重排进程交互 **8 秒**，包含证据组装、评分和进程通信，不包含前置检索或后续 LLM 生成。
- 完整馆藏编号、明确选择的作品、lexical 对照路径绕过重排。照片识别仍调用原 `search()`。
- 独立工作进程一次只处理一个任务；繁忙时立即使用原搜索，不排队。
- 超时、模型异常、响应身份不符时返回原搜索；直接结束工作进程，避免停止等待后模型仍占用 CPU。
- 单次超时／错误后熔断，后续持续使用原搜索。**本版需要重启服务恢复重排**，不自动重载大模型或重试。
- 请求取消会结束进程并传播取消；应用关闭时清理子进程。来源在等待期间被归档或替换时，成功和回退路径都不会返回旧版本。

此功能只改变候选排序，不把最高分当作确定身份或正确概率。相似器物仍需要候选确认。

## 配置与观察

```dotenv
MUSEUM_TEXT_RERANK=false
MUSEUM_RERANK_TIMEOUT=8
MUSEUM_RERANK_STARTUP_TIMEOUT=60
# MUSEUM_RERANK_MODEL 默认指向项目 models/bge-reranker-v2-m3；相对路径以项目根目录解析。
```

改配置后重启服务。关闭开关即回退，基础检索的 `MUSEUM_DENSE_VIEW` 无需随之改变。开启时单独建立 administrative 索引，增加启动编码与内存占用。重排模型逐文件核验本地清单 SHA256 和固定修订，只从现有本地文件加载、禁止远程代码、不调用模型 API。

启动检查最多等待 60 秒；模型缺失、损坏或初始化失败时停用重排，基础服务仍可用。健康接口 `/api/museum/health` 增加 `text_rerank.enabled/state/budget_ms`。

文字问答后台 Trace 的 `rerank` 记录状态、原候选、实验候选、实际排序、耗时、预算、原文片段 ID、选择／遗漏原因、证据哈希及模型修订。状态包括 disabled、bypassed、applied、busy、timeout、disabled_after_timeout、error 等。游客响应不带这些内部字段；现有 `/review` 的“查看候选、引用、生成过程与版本”可以查看完整 Trace。

## 修复接入漂移

首次尝试复用原索引已编码的向量，但小库 T14 的候选顺序与冻结实验不一致。最小对照固定同一道题、片段集合、融合方式，只将向量改为按 administrative 完整顺序重新编码：原先不一致，改后完全一致。批次相关的数值行为会影响相似片段的同分顺序，不能仅凭原文相同就直接替代向量。

已增加模拟批次相关编码输出的回归测试，先失败再修复；保留原索引用于回退，并独立编码实验索引。一次性探针已清理，私有诊断记录保留。

修复后重跑 **196 项（114 个不同问题）**：候选身份、顺序、各路命中片段／原文均与冻结实验一致，实测相似度最大差值为 **0**。这项检查回放上一轮缓存的重排分数，验证接入等价性；不是重新跑了 196 次真实 BGE 或生成答案。

## 实测

使用独立 FastAPI TestClient 应用、内存存储、300 件 V&A＋12 件 AIC；关闭生成式 API，使用真实本地 MiniLM 和 BGE。正式 `.env`、MongoDB 和网站进程未修改。

| 检查 | 结果 |
|---|---|
| 木雕、基督像、花器三题真实重排 | 20 秒验收预算下均成功，前五与冻结 v3 一致；HTTP 约 7.26／6.67／6.03 秒 |
| 默认 8 秒预算独立请求 | 基督像题成功，HTTP 约 6.75 秒，重排约 6.64 秒 |
| 强制 1ms 预算 | 子进程结束；HTTP 仍成功，约 106ms 返回原搜索；Trace 标记 timeout |
| 熔断后下一请求 | 约 52ms 返回原搜索，记录 disabled_after_timeout，不重启模型 |
| 关闭开关 | 约 54ms 返回原搜索，记录 disabled |

这些不是完整游客回答、手机网络延迟或并发 SLA；1ms 预算不意味着 HTTP 只需 1ms。默认预算只跑过一题成功请求，不能认定所有题都能在 8 秒内重排；前一轮完整评测 P95 超过 8 秒，部分请求会回退。

测试覆盖真实子进程超时退出、繁忙不排队、请求取消、异常响应、启动失败／超时、确定性查询绕过、来源归档、模型路径和 Trace 保存。全后端 **296 项通过**。没有修改前端，未将这些检查称为浏览器验收。

复现：设置 `PYTHONPATH=backend`、`HF_HUB_OFFLINE=1` 后运行 `python scripts/check_rerank_integration.py`，需要此前私有冻结语料和报告。脚本拒绝覆盖完成报告，不输出会话 token。公开单元测试不需要 V&A 私有数据或模型权重。
