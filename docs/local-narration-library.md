# 本地官方讲解底稿与三种中文讲法

2026-09-29。一个 V&A 作品的本地试点已接入；原有 AIC 数据继续保留。不是全馆讲解库，也不代表获得馆方授权或审核。

## 用户流程

首页选择作品 → 默认简明讲解 → 在回答中切换简明／深入／儿童版 → 可展开馆方英文原稿，或自由追问。

中文内容标记为“依据馆方英文讲解改写，非馆方官方中文稿”。当前三份底稿经过代理编辑、精确引文匹配和模型事实核对；`human_reviewed=false`，游客体验与儿童可理解性尚待人工评审。播放按钮继续使用浏览器朗读，不是馆方录音。

## 实现边界

- 默认配置不加载任何 V&A 材料。通过本地忽略的 `.env` 配置 `MUSEUM_PRIVATE_CORPUS`，加载私有记录；公开仓库只有通用代码和合成测试。
- 私有记录包含官方原稿、来源／讲述人、图片来源、源哈希和三个版本。原稿、图片、改写和检查日志均在 Git 忽略目录。
- `action=narration` 必须显式指定作品。来源处于 active、源版本和内容哈希一致、引文逐字存在、预备事实核对通过，才返回预备讲解。切换预备版本不再调用模型；不把速度改进当作已测得的线上性能指标。
- `action=question` 仍走原有检索与逐条事实核对；不会因为有固定稿就用固定稿回答任意问题。儿童风格成为显式 `children` 模式，深入为 `deep`。
- 缺失或失效的预备稿退回已存在的问答链路；没有模型时只展示资料，不把未核对稿冒充成功。
- 图片端点只读已配置私有目录内的图片，路径穿越被拒绝。图片用于本地作品选择；本轮没有重新验证 V&A 拍照识别成功率。
- 去掉本地 `MUSEUM_PRIVATE_CORPUS` 配置并重启，即回到公开 AIC 演示。无需改代码或删除原数据。

## 已验证

- 后端 92 项测试通过，含三个模式、无模型固定稿返回、源哈希失效、伪造引文、普通问答不串入固定稿、请求重放／冲突、私有加载开关与图片路径边界。
- 前端两个局域网 HTTP 请求编号回归通过，生产构建通过。
- 浏览器实际完成 V&A 入口 → 简明版 → 深入版 → 儿童版 → 展开馆方英文原稿。三版字数分别约 111、336、89（按当前文本字符串计数，包含标点和换行，不是朗读时长）。
- 同一浏览器会话追问“特里同正在做什么？”，实时问答返回吹海螺的事实及对应原稿引文，通过现有核对链路；没有返回固定讲解替代问题答案。
- 首轮自动稿的失败记录保留在私有评测目录；深入版出现审查器把结构要求与事实混淆的问题，儿童版出现截断后丢失观察任务的问题。当前修订稿经编辑后单独保存并重新核对，不覆盖首轮，不称为线上 A/B 测试。
