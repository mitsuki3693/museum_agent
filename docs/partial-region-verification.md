# 局部对应与非对称核对 v1（2026-10-07）

状态：已实现可回退的实验分支，完成本地回归、真实图片离线诊断，以及六张图四组各三次的真实 VLM 对照。**未启用到当前游客服务：可见性规则有局部收益，patch 未显示额外收益，格式失败仍待解决。** 馆藏维持 100 件 V&A（连同 AIC 共 112 条）；不新增视觉模型，不启用此前的多图模式。

## 可见性规则

原决策路径将 `different_work` 直接当作否决，即使具体证据只是顶部匹配、底座没有拍到。针对这一路径的回归测试先失败（`no_reliable_match`），修改后恢复为 `uncertain`。

新增 `visible_match / visible_conflict / not_visible / cannot_compare`，要求两侧明确可见且有描述，匹配或冲突才有效。没有有效冲突的 `different_work` 降为不确定；**没有独特正面匹配证据时仍不得生成身份候选**。原模型结论与规则撤销否决的标记分开记录。相似花器的展签保护、作品确认动作、候选 ID 校验继续保留。

代码只能检查模型提供的结构化可见性声明，不能证明它所说的部位在像素中确实可见。下面的开发图对照也不能替代独立图片与人工区域复核。

## 实验开关与控制变量

`MUSEUM_PHOTO_VERIFICATION` 默认 `legacy`：

| 值 | 作用 |
| --- | --- |
| `legacy` | 旧版候选联合核对，基线 |
| `visibility` | 同候选联合核对，使用新的可见性提示词、字段及规则 |
| `candidate` | 同一新规则，每次只核对一件候选；不加 patch 信息 |
| `partial` | 在 candidate 上动态选参考图并附算法建议局部 |

新分支每件最多一个参考视角、候选最多五件；实际评测固定视觉前三以控制调用量。旧文字召回和参考图补入仍保留在应用路径。评测的视觉 Top3 子实验不能被写作完整线上混合检索效果。VLM 必须恰好返回本次提供的候选；漏项、重复 ID 或串入别的候选均判失败。

## DINOv2 patch 模块

- 使用现有 DINOv2-small 的 256×384 patch 特征；全图 CLS 召回、权重和原排序不变。
- 独立 letterbox 到 224×224，不中心裁剪；过滤碰到填充区的网格，并将网格坐标映射回原图。
- 双向最近邻、固定相似度与歧义间隔、确定性局部仿射一致性筛选；同一查询对每张参考图计算局部匹配，按通过筛选的匹配数选择视角。
- 参考图 patch 有独立版本化缓存；内容、模型 revision、预处理版本绑定缓存键，校验形状/归一化/内容摘要/键。游客照片与向量不持久化。
- `coverage` 只表示有效查询网格的匹配比例，不是身份概率。默认分母包含真实照片背景；人工矩形 ROI 也不等于像素级前景分割。所有结果明确标记 `foreground_verified=false`。
- 无几何支持时沿用原参考图，不凭零分推断是不同作品。局部分数和裁剪只供核对参考，不能直接提升身份等级。

## 已执行的真实图片离线诊断

保留私有 12 图测试包、106 张参考图库，输出 36 张对应点示意图。本次只运行本地模型，没有调用 DeepSeek。原图与派生图全部留在 `eval/private`，不上传 GitHub。

| 案例 | 通过筛选的匹配数 | 观察 |
| --- | --- | --- |
| 人头花器全貌 → 正确作品 | 31 | 只能作为开发诊断 |
| 人头花器顶部 → 正确作品 / 相似纹章花器 | 15 / 13 | 分差很小，示意图含背景和重复纹样匹配 |
| 海神背面 → Samson / 正确海神 | 0 / 0 | 当前局部特征与视角覆盖没有给出可靠支持 |
| Cleveland 花器 → 两件 V&A 花器 | 23 / 23 | 库外相似作品也能产生匹配，不能按匹配数确认身份 |

固定匹配参数之后，人工查看图片并框选 05 的头部 `[.43,.04,.70,.25]`、08 的肩背 `[.23,.12,.51,.39]`，单独重跑两个诊断，两者均为 0 个通过筛选的匹配。这是人工矩形区域检查，不是自动分割，也不是已经找到正确对应。

这一结果说明当前粗网格匹配不能作为已验证的识别改进。它不能单独区分网格分辨率、特征区分能力、阈值和参考视角哪个因素贡献最大。下一次离线实验可以只改变局部分辨率或参考视角其中一项；不能同时改几项并归功于新算法。

2026-10-07，经用户明确授权执行六张图片、参考图与算法裁剪图外发，最多 150 次调用。模型为 `deepseek-flash`，温度 0，不自动重试。完成 72 次流程运行；它们是 **6 张已知开发图片的重复，不是 72 个独立样本**。候选 ID 和召回分数在同一图片的所有组间一致，脚本校验通过；每张图共用一次观察结果。仅比较视觉 Top3 核对阶段，不包含线上文字混合召回。

usage 共 146 条，已知总 Token 为 292,647；连接失败的未知消耗不计为零，不推算人民币费用。延迟包含本地处理；每张图片首次执行的组额外包含一次观察请求。样本小、部分运行提前失败，因此这里不是生产 P95，也不是严格隔离的性能基准。

结果存入本地 MongoDB `eval_runs`，ID 为 `partial-regions-20261007-v1`，标记 `human_reviewed=false`、`online_ab=false`。72 条为隔离实验摘要，不伪装为游客 Trace。原报告保存私有语料 JSON 的哈希；入库同时保存公共加私有语料的组合哈希，并明确两者范围。图片、裁剪、详细报告不上传 GitHub。

**部署决定：保持 `legacy` / `single`。** 下一轮先修复模型部位描述与结构化协议不一致的问题，保留原始失败及严格身份边界，然后同图对比 A/B。海神背面另外进行视角覆盖或局部特征实验，一次只改变一项。暂不扩大到 1000 件，不引入 Reranker、Milvus 或新视觉模型。

## 复现与后续工作

```powershell

```

`offline.json` 及对应图位于 `eval/private/partial-regions-v1`，ROI 结果另存 `partial-regions-roi-v1`。脚本禁止覆盖已有结果。

真实对照脚本固定 01/04/05/08/11/12 六张公开来源作品图、候选及参数，四种方案各三次，交替执行顺序；每张只生成一次观察描述并复用，共最多150次模型请求。不自动重试，保留 schema/服务失败。`live.json` 与 `summary.json` 均禁止覆盖；新一轮实验应另设版本，不能直接重复上述命令覆盖基线。重复运行同一图不是增加独立样本。

只有后续证据同时支持执行可靠、局部案例改善与库外误认不增加，才考虑启用新的游客默认行为。保持 `MUSEUM_PHOTO_VERIFICATION=legacy` 即可沿用旧流程；不删除图库、缓存或旧 Trace。

本轮 198 项后端自动化测试通过。包括实际 `PhotoRecognizer` 路径的三种实验模式、有效可见冲突、无证据不得提升身份、展签保护、逐候选 ID 约束、缓存损坏/键不符重算与坐标映射。旧 pytest 临时目录权限错误通过新建独立测试目录排除，没有修改业务逻辑来规避失败。
