## 为什么检查参考视角

上一轮部位字段修复后的海神背面图，三次均进入视觉 Top3，但没有返回身份候选。原核对选中了 `va-head` 头部参考，而不是能够解释肩背和披风的视角。已有三张海神参考不能充分覆盖该测试视角。
