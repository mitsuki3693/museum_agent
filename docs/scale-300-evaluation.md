## 文字：是否能找到对应作品

新增冻结开发题：10 件原有作品各 3 种表达，共 30 题；4 道无唯一答案的模糊描述；另 5 件新作品各有英文与中文题，共 10 题。题目由代码助手根据来源核对后在检索前冻结，**尚未人工复核，不是盲测或正式准确率**。

使用实际 `MuseumIndex.search()`，无指定作品强制置顶，无模型改写或答案生成。两组使用相同的本地多语言嵌入、BM25、RRF、切块和返回上限。只比较图库／语料大小。

## 运行耗时与证据边界

- 一次本机 CPU、4 线程对照：文字检索中位约 28 → 53 毫秒；图片检索约 219 → 219 毫秒。没有并发压测，也没有包含模型生成，不能写成线上端到端延迟或生产 P95。
- 300 件首次新增 200 张图像特征计算约 79 秒，106 张旧图命中缓存。随后 306 张全部缓存命中的加载约 1.35 秒（另一次约 5.65 秒）。没有声称这些启动时间稳定可复现到所有机器。
- 文字索引构建约 8.9 → 14.7 秒；当前仍启动时构建，尚未新增文字向量持久化。
- 第一次评测在保存文字结果时因 Windows 文件短暂占用中断，partial 与待写文件已保留。只为本地原子替换增加有界重试，然后全量复跑；没有更换问题、算法或删除坏案例。原始冷启动数据仍留在首次文件中。
- 全部工作在本地完成，付费模型 API 调用为 0，私有原图及馆方原文未上传 GitHub。

## 下一步优先级

1. **精确编号优先匹配**：编号属于确定字段，完整匹配应优先于模糊语义结果；保留来源回查和重复编号歧义处理。用上述 200 条和错误编号反例验收。
2. **中文对应能力**：给馆藏建立有来源核对的中文名称／别名与关键外观描述检索字段，原始馆方文本单独保留。优先对中英文对照失败分组验证，再用新题检查，避免只修当前题目。
3. **图片视角覆盖**：对排名明显下降的半身雕塑补独立参考视角；不得使用当前测试照片或其裁剪充当新参考。保持两候选＋补拍，不能把“前五有正确作品”当作完成确认。
4. 上述质量检查通过后，再决定启用 300 件版本及扩至 1,000 件。暂不增加 Milvus 或继续投入本轮已停止的局部重排。

## 复现与留档

```powershell
.venv/Scripts/python.exe scripts/import_va_pilot.py --target 300 --folder va-pilot-300-v1 --base-corpus va-pilot-100-v1-corpus.json --base-references va-pilot-100-v1-references.json
.venv/Scripts/python.exe -X utf8 scripts/evaluate_scale_300.py
```
