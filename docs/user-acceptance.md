# MUSE 用户收尾验收清单

建议预留 20 至 30 分钟。你主要判断手机是否顺手、讲解是否有用，以及识别不准时能否继续完成任务；不需要重做数据库和自动化测试。

## 打开方式

- 电脑：[打开 MUSE](http://127.0.0.1:3000/)。
- iPhone：[同一 Wi-Fi 打开 MUSE](http://192.168.2.4:3000/)。这是本次核实的电脑地址，换网络后可能变化；电脑与服务保持开启。
- 后台：[运行记录和评测](http://127.0.0.1:3000/review#evaluations)，使用本机已有管理凭据，不需要注册工作人员账号。

图片使用已有的 `data/private/MUSE-test-pack-12-20261006/`，里面有带序号的 12 张测试图。上传支持 8 MB 以内 JPG、PNG、WebP；不要直接传 HEIC。可以用手机拍电脑上的作品图，但记录这是拍屏测试，不当作真实馆内拍摄。

每换一件作品点“新对话”，同一件的追问和补拍保持在原对话里。后台保存问题、候选、操作与反馈，不保存上传原图，所以失败时请留下文件编号或截图以及大致时间。

## 需要你测试的十二项

| 编号 | 具体操作 | 重点看什么 |
| --- | --- | --- |
| T01 | 点“选件作品”，翻页并打开一件以前没测过的馆藏 | 图片和名称对应；没有图片的记录有说明；资料少时不编长故事 |
| T02 | 新对话输入 `C.615-1925`，确认目标后问“作者是谁”“什么年代”“什么材质” | 编号找到正确馆藏；回答来自对应资料，不串到上一件 |
| T03 | 新对话输入“红漆的椅子，上面有蝙蝠和云纹” | 是否给出对应图片供确认；不要在顶部列表框里测语义搜索 |
| T04 | 相册上传 `01_人头花器_全貌.jpg` | 正确花器是否出现在前两项；手动确认后再讲解，不应提前认定身份 |
| T05 | 新对话上传 `05_人头花器_顶部局部.jpg` | 正确候选或诚实的不确定；失败时可补拍 01 全貌；补拍一次仍失败应提供文字／浏览入口 |
| T06 | 新对话上传 `08_海神雕塑_背部局部.jpg` | 这是已知困难案例。如果出现参孙，请点“都不是”并记失败；随后补拍 04 海神全貌，观察能否完成任务 |
| T07 | 上传 `11_Cleveland花器_库外反例.jpg` | 不能把外馆作品说成确定的 V&A 馆藏；相似浏览必须明确未确认原图身份；错误高置信候选也记录为失败 |
| T08 | 上传 `12_阿波罗与达芙妮_库外反例.jpg` | 同样记录是否错列馆内雕塑；安全拒识、相似推荐、错列候选分别记，不合并成“识别成功” |
| T09 | 用“选件作品”选《Neptune and Triton》或之前有讲解的作品，先简明，再点“讲给孩子听”“深入一点” | 风格有变化、中文自然；人物、年代等事实一致。资料不足应说明，不能为了深入新增故事 |
| T10 | 同一作品继续问“它有什么值得观察的细节”，再问“制作者制作当天早餐吃了什么” | 前者承接作品；后者说明资料不足。检查每条引用是否真能支撑回答 |
| T11 | 问“厕所在哪里”，再试出口、楼梯／电梯、服务台；进入路线和地图案例 | 操作能完成；模拟位置有标识；不能声称真实定位你，也不能编最近厕所距离 |
| T12 | 用语音输入一句问题、确认文字后发送，播放一次讲解；分别点一次“有帮助”或“事实有误” | iPhone 权限和播放正常；反馈旁出现“已记录”。如果浏览器语音不可用，文字和相册仍能继续 |

T03 至 T08 多为已有开发案例，主要验证不退化，不用来宣称独立测试准确率。T01 的新作品可以留下原始提问，之后再独立评分；本轮不要为了找一个成功结果反复改问法而忽略首次失败。

## 怎么把结果发给我

不用写长报告。每项填“通过／失败／没测”，失败时补充：

```text
T06：失败
时间：22:10 左右
图片：08 海神背部局部
实际：第一项参孙，第二项没有海神
操作：都不是 → 补拍04 → 找到海神
补拍后任务：完成
截图：附上失败那一屏
```

照片回答下方的“候选不对／仍需帮助”用于识别反馈；文字回答下方的“事实有误／没有解答”用于问答反馈。都可以记录，但它们不能代替注明用了哪张照片。

普通无匹配、服务不可用、错误候选和错误确认是四种不同情况。服务故障请记录时间、网络情况与页面提示，不自动算算法识别失败，也不要只保留重试成功的结果。

## 收尾判断

阻断问题：打不开、发送卡死、照片未确认就进入错误身份讲解、串作品、无提示丢反馈、资料不足却编造事实。出现这些问题需要修复后再验收。

可保留并说明的边界：困难局部照片需要补拍、馆外作品拒识、部分资料不足、浏览器语音能力受限。不能把困难图的错列候选记成通过，但可以在演示中展示“拒绝候选→补拍／文字查找”的恢复流程。
